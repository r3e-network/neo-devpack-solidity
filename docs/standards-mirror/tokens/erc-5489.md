## ERC-5489: NFT Hyperlink Extension

ERC-5489 lets NFTs carry **embedded hyperlink slots**: the holder
allocates URL "slots" on their NFT and assigns each slot to a delegate
who controls the link target. Used for:

- **Promotional NFTs** — brands buy hyperlink slots on popular
  collections, link to their landing pages.
- **Sponsored content** — NFT holders monetise their NFT's hyperlink
  slots without giving up ownership.
- **Composable references** — slot 1 → wiki, slot 2 → marketplace,
  slot 3 → forum thread.
- **Time-limited promotions** — slots expire so the URL doesn't get
  stuck pointing at a dead campaign.

The owner allocates slots; each slot has a **slotURI controller**
(could be the owner themselves, or a delegated bidder); the controller
sets / updates the URL.

### Required Interface

```solidity
interface IERC5489 {
    event SlotUriUpdated(uint256 indexed tokenId, address indexed slotManagerAddr,
                         string slotUri);

    function setSlotUri(uint256 tokenId, string calldata newUri) external;
    function authorizeSlotTo(uint256 tokenId, address slotManagerAddr) external;
    function revokeAuthorization(uint256 tokenId, address slotManagerAddr) external;
    function revokeAllAuthorizations(uint256 tokenId) external;

    function getSlotUri(uint256 tokenId, address slotManagerAddr)
        external view returns (string memory);
}
```

Each `slotManagerAddr` holds an independent slot. The owner can revoke
slot authorizations at any time.

### Neo Equivalent: NEP-11 + (tokenId, manager) URL Storage

```csharp
public static void AuthorizeSlotTo(ByteString tokenId, UInt160 manager)
{
    if (!Runtime.CheckWitness(OwnerOf(tokenId))) throw new Exception("NEP11:NotOwner");
    Storage.Put(Storage.CurrentContext, AuthKey(tokenId, manager), 1);
}

public static void SetSlotUri(ByteString tokenId, string newUri)
{
    var manager = Runtime.CallingScriptHash;
    if (!Runtime.CheckWitness(manager)) throw new Exception("NEP11:NoAuth");
    if (Storage.Get(Storage.CurrentContext, AuthKey(tokenId, manager)) is null)
        throw new Exception("NEP11:NotAuthorised");
    Storage.Put(Storage.CurrentContext, UriKey(tokenId, manager), newUri);
    OnSlotUriUpdated(tokenId, manager, newUri);
}

public static string GetSlotUri(ByteString tokenId, UInt160 manager)
    => (string)Storage.Get(Storage.CurrentContext, UriKey(tokenId, manager));
```

### Composition

- **[ERC-7160](./erc-7160)** — multi-metadata. ERC-5489 slots
  complement multi-metadata: pinned metadata + per-slot promotional
  URLs.
- **[ERC-2135](./erc-2135)** — consumable. Promotional NFTs may have
  consumable slots (one-shot redemption).
- **[ERC-7432](./erc-7432)** — roles. Use roles for the slot manager
  delegation if a richer permission model is needed.

### Migration Notes

For Solidity NFT collections monetising slots:

1. Replace the slot authorization mapping with a Neo storage prefix.
2. The slot URI storage uses the same per-(tokenId, manager) shape.
3. Revocation = storage delete on the auth + URI keys.
4. Renderers (wallets, marketplaces) iterate the manager prefix to
   show all active slot URIs for an NFT.

For NFT-as-billboard use cases, this is the standard. Wallets render
the active slot URIs as a small panel beneath the NFT's primary
metadata.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract ERC5489 {
    mapping(uint256 => mapping(address => bool))   public isAuthorised;
    mapping(uint256 => mapping(address => string)) internal _slotUri;

    event SlotUriUpdated(uint256 indexed tokenId, address indexed slotManagerAddr, string slotUri);

    function authorizeSlotTo(uint256 tokenId, address manager) external {
        // ... owner check ...
        isAuthorised[tokenId][manager] = true;
    }

    function setSlotUri(uint256 tokenId, string calldata newUri) external {
        require(isAuthorised[tokenId][msg.sender], "not authorised");
        _slotUri[tokenId][msg.sender] = newUri;
        emit SlotUriUpdated(tokenId, msg.sender, newUri);
    }

    function getSlotUri(uint256 tokenId, address manager) external view returns (string memory) {
        return _slotUri[tokenId][manager];
    }
}

<template #csharp>

```csharp
using System;
using System.ComponentModel;
using Neo;
using Neo.SmartContract.Framework;
using Neo.SmartContract.Framework.Attributes;
using Neo.SmartContract.Framework.Native;
using Neo.SmartContract.Framework.Services;

namespace R3E.Examples;

[DisplayName("HyperlinkNFT")]
[ContractPermission("*", "*")]
[SupportedStandards(NepStandard.Nep11)]
public class HyperlinkNFT : Nep11Token<TokenState>
{
    public override string Symbol => "LINK";

    private const byte Prefix_Auth = 0x60;
    private const byte Prefix_Uri  = 0x61;

    [DisplayName("SlotUriUpdated")]
    public static event Action<ByteString, UInt160, string> OnSlotUriUpdated;

    public static void AuthorizeSlotTo(ByteString tokenId, UInt160 manager)
    {
        if (!Runtime.CheckWitness(OwnerOf(tokenId))) throw new Exception("NEP11:NotOwner");
        Storage.Put(Storage.CurrentContext, AuthKey(tokenId, manager), 1);
    }

    public static void RevokeAuthorization(ByteString tokenId, UInt160 manager)
    {
        if (!Runtime.CheckWitness(OwnerOf(tokenId))) throw new Exception("NEP11:NotOwner");
        Storage.Delete(Storage.CurrentContext, AuthKey(tokenId, manager));
        Storage.Delete(Storage.CurrentContext, UriKey(tokenId, manager));
    }

    public static void RevokeAllAuthorizations(ByteString tokenId)
    {
        if (!Runtime.CheckWitness(OwnerOf(tokenId))) throw new Exception("NEP11:NotOwner");
        var ctx = Storage.CurrentContext;
        var iter = Storage.Find(ctx, AuthPrefix(tokenId), FindOptions.KeysOnly | FindOptions.RemovePrefix);
        while (iter.Next())
        {
            var manager = (UInt160)(byte[])iter.Value;
            Storage.Delete(ctx, AuthKey(tokenId, manager));
            Storage.Delete(ctx, UriKey(tokenId, manager));
        }
    }

    public static void SetSlotUri(ByteString tokenId, string newUri)
    {
        var manager = Runtime.CallingScriptHash;
        if (!Runtime.CheckWitness(manager))                            throw new Exception("NEP11:NoAuth");
        if (Storage.Get(Storage.CurrentContext, AuthKey(tokenId, manager)) is null)
            throw new Exception("NEP11:NotAuthorised");
        Storage.Put(Storage.CurrentContext, UriKey(tokenId, manager), newUri);
        OnSlotUriUpdated(tokenId, manager, newUri);
    }

    public static string GetSlotUri(ByteString tokenId, UInt160 manager)
        => (string)Storage.Get(Storage.CurrentContext, UriKey(tokenId, manager));

    private static byte[] AuthKey(ByteString tokenId, UInt160 manager)
        => new byte[] { Prefix_Auth }.Concat(tokenId).Concat(manager);
    private static byte[] UriKey(ByteString tokenId, UInt160 manager)
        => new byte[] { Prefix_Uri }.Concat(tokenId).Concat(manager);
    private static byte[] AuthPrefix(ByteString tokenId)
        => new byte[] { Prefix_Auth }.Concat(tokenId);
}
```
