## P3 Deep Architecture Improvements

### Item 1: Oracle getrequest
- Added `"getrequest"` match arm in `oracle.rs` returning NeoVM Map with 7 fields

### Item 2a: Arithmetic Gas Scaling
- Added `ARITH_PER_BYTE_GAS = 3` for MUL/DIV/MOD/POW/MODMUL/MODPOW in `binary.rs`

### Item 2b: Dead GasTracker Code
- Removed `named_operation_cost()`, simplified `consume_gas(Option<u64>)` → `consume_gas(u64)`, batch-updated 26 bridge call sites

### Item 4: ByteString/Buffer Type Distinction
- Added `ByteArrayType` enum (ByteString=0x28, Buffer=0x30) with `type_tag` on `StackItem::ByteArray`
- Constructors: `StackItem::byte_array()` (ByteString), `StackItem::buffer()` (Buffer)
- EQUAL type-strict: `(ByteString, Buffer)` → false
- ISTYPE split: 0x28 checks ByteString, 0x30 checks Buffer
- CONVERT tags output by target type; REVERSEITEMS rejects ByteString; MEMCPY requires Buffer dest
- NEWBUFFER/CAT/SUBSTR/LEFT/RIGHT emit Buffer-tagged ByteArrays
- Updated 40+ match arms in src/ + 3 in tests/

### Item 3: Streaming Iterator
- Added `start_after_key` field to `StorageQuery` for cursor-based pagination
- Created `StreamingCursor` struct (prefix, options, last_key, exhausted, page_size)
- `IteratorState` now has optional `cursor: Option<StreamingCursor>` for lazy page fetches
- `query_storage_page()` — queries host with cursor, returns shaped entries + last key
- `allocate_streaming_iterator()` + `refill_iterator_buffer()` — lazy fetch on buffer exhaustion
- `shape_raw_entries()` — per-page overlay merging using key range tracking
- `System.Storage.Find` uses streaming allocation (page_size=50)
- `System.Iterator.Next` triggers refill on buffer exhaustion
- Files: state.rs, storage_ops.rs, storage.rs, iterators.rs, storage_types.rs, query.rs, state_storage.rs
