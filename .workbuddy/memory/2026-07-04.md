## Architecture Design — Long-Term Evolution Plan

### Deliverables
- `docs/architecture-design.md` — Full architecture document (9 sections)
- `docs/adr/adr-001-to-006.md` — 6 Architecture Decision Records

### Key Decisions
- **ADR-001**: Hexagonal architecture — 6 bounded contexts (Parser, IR, Codegen, Optimizer, Manifest, Runtime)
- **ADR-002**: Runtime as separate bounded context via `RuntimePort` trait
- **ADR-003**: 3 trait-based extension points (SolidityVersion, NativeContractHandler, OptimizerPass)
- **ADR-004**: Strangler fig migration — 5 phases from v0.29.x to v1.0, zero test regressions
- **ADR-005**: Shared kernel immutability rule (no I/O, no state mutation, no business logic)
- **ADR-006**: Directory depth limit ≤4 levels

### 5-Phase Roadmap
1. Phase 1 (v0.29.x): CLI decomposition — extract codegen/optimizer/manifest (LOW RISK)
2. Phase 2 (v0.30.x): Runtime isolation — decouple 4 subsystems via port (MEDIUM RISK)
3. Phase 3 (v0.31.x): Extension points — trait plugins (LOW RISK, parallel with Phase 2)
4. Phase 4 (v0.32.x): File refactoring — break 13 files >800 lines (MEDIUM RISK)
5. Phase 5 (v1.0, optional): Crate split — workspace (HIGH RISK, only if needed)
